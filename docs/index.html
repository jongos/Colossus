Developer-Workspace Auditor

Evidence First.
No Cleanup.

Colossus is an evidence-first developer-workspace auditor: a Rust CLI with a portable Codex/Claude skill. Phase 1 inventories explicitly selected roots and identifies questions worth investigating. It performs no cleanup.

Status: experimental Windows-first read-only milestone 7 (v0.7.0). Every candidate remains protected. No file is declared proven disposable. Linux and macOS scanning fail explicitly; they are future work.

Build and Use ↓Project Overview

The Problem

Developer folders take up disk space. Some of it is files a tool generated and could be rebuilt. Some of it is someone’s work.

Before anyone cleans up, they need to know what is there, who owns it and whether it can be recovered.

What This Does About It

Colossus is a program for Windows that only looks and never changes anything, plus a skill for AI agents (a folder of instructions you add to an agent). You choose which folders it may look at. It lists what is in them and raises questions worth checking, with the evidence behind each.

It does not delete anything. It treats every candidate as protected and never says a file is safe to delete. It is experimental, and it only scans Windows so far.

Example. colossus audit --root C:\dev\example --format text prints a text report on that one folder.

Build and Use

Select the Roots.
Read the Report.

With a Rust toolchain and a compatible Windows linker:

cargo build --release --locked
.\target\release\colossus.exe audit --root C:\dev\example --format text
.\target\release\colossus.exe audit --root C:\dev\example --root D:\dev\other --format json --output C:\audit-reports\new-audit.json
.\target\release\colossus.exe audit --root C:\dev\example --provenance --format json

The output parent must already exist outside the scan roots. Existing output files are never overwritten. Without --output, reports go to stdout; do not redirect stdout into a scanned root. Exit status: 0 = complete within stated inventory limits; 2 = incomplete; 130 = cancelled; 1 = error.

Boundaries

What the Scanner Does Not Do.

No side effects

The scanner does not install packages, run build scripts, invoke Git, access the network or send telemetry. Repository configuration and README instructions are never executed.

No proof of disposability

Claims, checksums and equal hashes never authorize cleanup. Every candidate remains protected, and a report may reveal private paths and project names, so it is not uploaded automatically.

Skill

The Same Skill for Codex and Claude Code.

The skill folder works with Codex and Claude Code. Copy it to the appropriate personal skill directory (~/.codex/skills/colossus or ~/.claude/skills/colossus) after building and placing the executable on PATH. The project does not alter agent configuration or install itself automatically.
